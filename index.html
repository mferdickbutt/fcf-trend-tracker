Formulas and conventions

  • Capex sign convention: Capex is recorded as a positive cash outflow (spend). Free cash flow = operating cash flow − |capex|. Absolute value is applied so a negative (filing-style) capex still uses the same formula.
  • Free cash flow: FCF = OCF − |capex|
  • FCF margin: FCF margin = free cash flow ÷ revenue. Returns null when revenue is zero, missing, or non-finite so the result is never NaN or Infinity.
  • MoM change: current − previous. Percent change uses |previous| as the denominator and returns null when previous is zero.
  • Cumulative FCF: running sum of monthly free cash flow.
  • Target comparison: actual − target; a month meets the FCF target when actual ≥ target ($40.0M FCF, 10.0% margin).

9 of 18 months met the FCF target. Null, empty, or non-finite inputs return null rather than NaN or Infinity.
